Nutrition Tracker

A lightweight web application for tracking nutritional values of Albert Heijn products. Users can search for products, enter volume, and then receive the calculated totals for its nutritional values.
Currently available at: https://ah-nutrition-tracker.onrender.com/

Features:
- Search a database of ~35,000 Albert Heijn products
- Enter quantities in grams or millilitres
- Automatically calculate nutritional totals
- Maintain a temporary basket of products
- Mobile-friendly web interface
- SQLite database for product and nutrition data
- Python & Technical Skills

This project was built primarily with Python, focusing on practical backend development:

FastAPI — REST API design and request handling
Web scraping — Collecting and parsing product data from Albert Heijn
SQLite — Database design and SQL queries
Data modelling — Separating product metadata from nutritional information
API design — Endpoints for product search, basket management, and nutritional calculations
HTTP & web protocols — Working with requests, responses, headers, and external web services

The project was built as a useful tool for daily life and a practical way to develop experience with Python backend development, APIs, databases, web scraping, and deploying a complete application.
